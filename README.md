# Underdog - Fighting Simulator Game

A 3D fighting simulator game built in Unity where you play as an underdog character fighting against progressively stronger AI enemies.

## Features

- **3D Combat System**: Real-time 3D fighting mechanics
- **Attack Combos**: Chain attacks together for powerful combo moves
- **Health & Stamina**: Manage resources during combat
- **AI Enemies**: Multiple enemy types with different combat styles
- **Character Progression**: Level up, gain experience, and unlock abilities
- **Blocking & Defense**: Strategic defensive mechanics
- **Dynamic Difficulty**: Enemies scale with player progression

## Quick Start

1. Clone the repo: `git clone https://github.com/i240503-hue/underdog.git`
2. Open in Unity 2022.3 LTS or newer
3. See `SETUP.md` for detailed setup instructions

## Controls

- **WASD**: Move
- **Space**: Jump
- **Left Click**: Light Attack
- **Right Click**: Heavy Attack
- **Q**: Block
- **E**: Special Ability
- **Shift**: Sprint
